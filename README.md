# Итоги урока — демо, версия 2

Публичный прототип на GitHub Pages: https://borisbell.github.io/lesson-grade-demo/

## Сборка и публикация

Нужен Node.js 22 или новее. Устанавливать зависимости не требуется.

```sh
npm test
npm run build
npm start
```

Готовый билд находится в `dist/`: HTML, CSS, JavaScript, шрифты, изображения, аудио и видео. Сборка проверяет синтаксис JavaScript, наличие локальных ресурсов и относительные пути, чтобы прототип работал по адресу `/lesson-grade-demo/`. Локальный просмотр: http://127.0.0.1:4173/.

Workflow `.github/workflows/pages.yml` проверяет проект и публикует **только `dist/`** после каждого push в `main`. Для первой публикации в репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Если первый запуск произошёл до включения Pages, повторите его через **Actions → Publish prototype to GitHub Pages → Run workflow**.

Все сценарии работают в браузере без авторизации и сервера. Форма записи демонстрационная: номер телефона не отправляется. Звук и видео подчиняются ограничениям автоплея браузера.

## Сценарий

Перед наградой за урок нужно решить три интерактивных задания: собрать 596, 358 и 742 из сотен, десятков и единиц. Детали перетаскиваются мышью или пальцем из нижней панели в серый контейнер; также доступны выбор детали и ячейки нажатием или с клавиатуры. Неподходящие детали возвращаются, верный ответ подсвечивает машинку зелёным. После третьего ответа появляется «Урок пройден». «Назад» и перезапуск отменяют незавершённое задание без награды.

Проверки без установки зависимостей: `node tests/math-exercise.test.cjs` и `node tests/flow.test.cjs`.

Результат 3,2 использует ту же анимацию награды 1,7 секунды: зелёный сундук на 3 из Figma 5473:27134 открывается, из него вылетают яйца, счётчик дорастает до 10. При смене результата спрайты и целевое число переключаются вместе; обе пары изображений загружаются заранее.

Изображение трёх сундуков на экране приглашения родителя обновлено из Figma 5218:8153: синий 4, фиолетовый 5, зелёный 3. Область и кадрирование соответствуют обновлённому макету, на мобильном сохраняются пропорции.

Для результата 4,8 награда появляется за 1,7 секунды: закрытый сундук на 4 встряхивается, открывается, из него вылетают яйца, затем счётчик дорастает до 30. Спрайты взяты из Figma 5460:26036. Анимация повторяется при переключении на 4,8 и открытии готовой аналитики; уход со страницы и смена результата отменяют текущую последовательность. При уменьшении движения в системных настройках сразу отображается итоговая награда.

28 октября: прогресс подготовки ускорен ещё вдвое, до 2,63 секунды. Фото преподавателя и серый/цветной сундуки обновлены из Figma. Результат 3,2 даёт 10 яиц, 4,8 — 30. «Посмотрю потом» возвращает на математику: уроки темы пройдены, вместо оценки доступен цветной сундук. Он снова запускает подготовку оценки с озвучкой; после просмотра итога заменяется на оценку. Повторные пропуски сохраняют доступный сундук, перезапуск демо возвращает начальное состояние.

Экран приглашения родителя автоматически воспроизводит предоставленную аудиозапись parent-invitation.mp3. Уход на другой экран или со страницы останавливает её и сбрасывает на начало; кнопка звука повторяет запись. На мобильном результате заголовок в одну строку с многоточием, внутренние отступы 16 px, круг и награда уменьшены ещё на 20%, отступы над и под ними 4 px, кнопка «Подробнее» — 48 px.

Заголовки промоблоков используют предоставленный Oceanic Grotesk Condensed Extrabold, локально подключённый в формате WOFF.

Запись из промежуточного итога открывает форму поверх текущей страницы.

Сценарий: активный урок → три математических задания → 5 яиц → приглашение родителя и прогресс примерно за 2,63 секунды → готовая оценка → пример 27 + 36 → итоги 4,8 с наградой 30 яиц → дополнительная награда с промокодом → математика с оценкой 4,8 и следующим активным уроком. Заголовок результата: «Урок: сложение и вычитание». Под оценкой 3,2 отображается «Средне», под 4,8 — «Хорошо».

Кольцевая диаграмма, правильность и скорость анимируются. Серый круг сразу виден полностью, поверх него заполняется только цветная дуга. Основные итоги: 96% против 72%, 6 против 8 минут. «Подробнее» раскрывает три задания; «Скрыть» сворачивает их. В результате 4,8 воспроизводится предоставленный пользователем Showreel_1-4_short.mp4: автоматически, без звука, по кругу. При смене результата или уходе с экрана видео ставится на паузу. Для результата 3,2 фото и подпись репетитора обновлены по Figma: Васильева Жанна, математика, стаж 8 лет. Десктопный попап записи расширен до 820 пикселей.

После завершения сценария оценка 4,8 на странице математики открывает готовые итоги. Клик по оценке промежуточного итога раздела показывает вариант 3,2 с поддержкой репетитора, правильностью 60% и скоростью 8 минут. Его кнопка записи открывает форму телефона. В актуальном макете боковую панель заменяет промежуточный итог в ленте уроков.

Запись открывает модальную форму с валидацией телефона, подтверждением заявки и повторным вводом. Форма демонстрационная, данные не передаются на сервер. Промокод копируется кнопкой; «Использовать промокод» возвращает к записи. «Посмотрю потом» пропускает оценку; «Повторить демо» сбрасывает сценарий.

Адаптивный HTML/CSS/JS без зависимостей. Ассеты локальные в dist/assets/. Oceanic Grotesk Condensed Extrabold подключён локально; для Factor A используется системный запасной шрифт. Reduced motion сокращает анимации.

Локальный запуск: node server.cjs, затем http://127.0.0.1:4173.

Основные файлы: dist/index.html, dist/flow-v2.js, dist/dashboard.js, dist/lesson-update.css, dist/math-exercise.js. Проверки входят в `npm test`.
