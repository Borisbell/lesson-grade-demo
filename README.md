# Итоги урока — демо, версия 2

Отдельный сайт из локальных исходников первой версии. Исходный опубликованный сайт не изменяется.

Макеты: https://www.figma.com/design/DKRL09OrAL3vGQPOqgSg65?node-id=5218-7717

Сценарий: «Исследуй планету» → награда 5 яиц → приглашение родителя и заполнение прогресса за 7 секунд → готовая оценка → пример 27 + 36 → подробные итоги → дополнительная награда с промокодом → математика с оценкой 4 и активными «Порядковыми числительными».

Итоги появляются последовательно: статистика, анимация диаграммы и счётчиков, оценка, сундуки, предложение трёх бесплатных занятий и подробные результаты. Системная настройка reduced motion сокращает анимации, но сохраняет ожидание 7 секунд.

На странице математики сайдбар скрыт до первой оценки, как в новом макете. После завершения сценария он показывает результат и блок репетитора; «Подробнее» открывает готовые итоги. «Повторить демо» возвращает исходное состояние.

«Посмотрю потом» отменяет ожидание и открывает дополнительную награду без выставления оценки. Промокод копируется кнопкой; «Использовать промокод» возвращает к форме занятий после получения оценки. Форма телефона демонстрационная, данные не передаются на сервер. Состояния успешной заявки и повторного ввода сохранены.

Статический HTML/CSS/JS без зависимостей. Все изображения сохранены локально в dist/assets/. Фирменные шрифты Factor A не предоставлены, используется системный запасной шрифт.

Локальный запуск: node server.cjs, затем http://127.0.0.1:4173.

Основные файлы: dist/index.html, dist/flow-v2.js, dist/new-flow.css, dist/dashboard.js. Проверка логики: node ../output/check-demo-v2.cjs.
